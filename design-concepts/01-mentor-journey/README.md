# Mentor Journey - Design Concept

## Design Philosophy

**Remove pressure by reframing as guided observation with a mentor.**

You're not diagnosing alone—you're learning to see what experts see with Dr. Plexus walking you through hospital rounds.

## Key Features

- **Mentor Sidebar (Always Visible)**: AI mentor provides instant, gentle commentary after every action
- **No Judgment Language**: Framed as "What you saw" vs "What you'll see after 100 rounds"
- **Soft Prompts**: Questions like "Want to explore symptoms?" instead of direct commands
- **Progress as "Rounds Walked"**: Not tests passed, but learning experiences accumulated

## What Problem Does It Solve?

**Primary Issue**: Users feel stressed and stupid when they can't diagnose correctly.

**Solution**: The mentor removes the test anxiety entirely. You're *supposed* to not know yet—you're learning with guidance. The focus shifts from performance to observation and pattern recognition.

## User Testing Questions

1. **Does this reduce stress?** Watch if users hesitate less when starting.
2. **Do they read the mentor comments?** This is the core learning mechanism—are they paying attention to it?
3. **Does it feel collaborative?** Do they mention feeling "guided" rather than "tested"?
4. **Do they want to do more cases?** Does the "rounds" metaphor make 1000 cases feel achievable?

## How to Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Design Details

- **Color Palette**: Calm professional blues (#4a7c9e, #6ba3c9, #e8f4f8)
- **Typography**: Clean sans-serif, readable, welcoming
- **Layout**: Split screen with mentor always visible on right
- **Tone**: Warm, encouraging, educational

## Best For

Students who want gentle guidance and feel intimidated by the traditional "test" format. Emotionally intelligent learners who respond well to supportive feedback.
