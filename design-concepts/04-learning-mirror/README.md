# Learning Mirror - Design Concept

## Design Philosophy

**Make learning visible in real-time. Every action shows what you're learning.**

Split-screen design where the right side mirrors your actions with instant learning annotations. Growth is never hidden—it's constantly celebrated.

## Key Features

- **Split-Screen Layout**: Patient interaction (left) | Learning annotations (right)
- **Real-Time Annotations**: Every action instantly shows what skill you're building
- **Skill Tags**: Visual tags for "History taking → Timing assessment", "Pattern recognition", etc.
- **Neural Network Metaphor**: "Neural pathways strengthened: 4 case patterns"
- **Brain Map Visualization**: Shows growing skill network after each case
- **Meta-Learning Focus**: Users see *how* they're learning, not just *what* they learned

## What Problem Does It Solve?

**Primary Issue**: Users don't focus on the AI guider's reasoning lessons—the core learning mechanism.

**Solution**: Makes the learning commentary impossible to ignore. It's right there, in real-time, every step. Users naturally shift attention to the "mirror" to see what they're building.

## User Testing Questions

1. **Do they read the learning mirror?** This is critical—do their eyes go to the right pane?
2. **Does seeing skill tags motivate them?** Do they mention "building skills" or "learning"?
3. **Is the brain map compelling?** Do they want to see it grow?
4. **Do analytical learners respond?** This concept targets meta-learners who like structure.

## Design Details

- **Color Palette**: Clean educational (#f5f7fa, #2563eb, #10b981, #8b5cf6)
- **Typography**: Modern sans-serif, readable, structured
- **Layout**: 50/50 split-screen, equal emphasis on action and learning
- **Tone**: Educational, growth-focused, transparent

## Best For

Analytical, meta-learners who want to see their progress explicitly. Those who like Duolingo's "You learned X" notifications and productivity dashboards.
